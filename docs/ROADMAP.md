# 开发路线图

## Phase 1 — 基础骨架与日记提取

> 目标：用户能在 CLI 里对话，Agent 能识别回忆内容并提炼为日记存入 SQLite。

| Spec | 功能 | 状态 |
|------|------|------|
| S001 | 项目骨架：CLI 入口、Agent 主循环、LLM 适配器接口 | 未开始 |
| S002 | 日记提取：从对话中识别回忆内容，提炼为结构化日记 | 未开始 |
| S003 | 日记存储：SQLite 持久化、基础 CRUD | 未开始 |

**完成标准**：能在终端对话，讲一段经历后 Agent 自动生成一条日记并存入数据库。

## Phase 2 — 日记检索

> 目标：用户能通过自然语言检索历史日记。

| Spec | 功能 | 状态 |
|------|------|------|
| S004 | 关键词检索：SQLite FTS5 全文搜索 | 未开始 |
| S005 | 语义检索：云端 Embedding + 本地向量库 | 未开始 |
| S006 | 混合检索：关键词 + 语义融合排序 | 未开始 |

**完成标准**：能通过"关于奶奶的日记"这类查询检索到相关日记。

## Phase 3 — 记忆系统

> 目标：Agent 拥有跨会话记忆，对话有连续性。

| Spec | 功能 | 状态 |
|------|------|------|
| S007 | 记忆存储：三层记忆架构（工作/短期/长期） | 未开始 |
| S008 | 记忆压缩：Hook 机制 + 压缩策略（待定） | 未开始 |
| S009 | 记忆注入：会话启动时自动注入相关记忆 | 未开始 |

**完成标准**：新开一个会话，Agent 仍然记得之前的偏好和重要事实。

## Phase 4 — 打磨与扩展

| Spec | 功能 | 状态 |
|------|------|------|
| S010 | 基于日记生成（周报、回忆录等） | 未开始 |
| S011 | Ollama 本地模型适配 | 未开始 |
| S012 | 日记导出（Markdown / PDF） | 未开始 |
