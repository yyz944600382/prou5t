## 实现过程

1. 安装依赖：@anthropic-ai/sdk, openai, @clack/prompts, dotenv, tsx, typescript, vitest
2. 实现 config → adapters → hooks → agent core → CLI 入口
3. 踩坑：
   - tsconfig moduleResolution 从 Node16 改为 bundler（避免强制 .js 后缀）
   - OpenAI SDK v6 类型变更：ChatCompletionMessageToolCall 变为联合类型，需 filter
   - HookRegistry 的 `fn.call()` 类型安全问题，改用 switch/case 显式调用

## 反思

- OpenAI SDK v6 的类型系统比 v4 复杂很多，后续如果遇到更多类型问题可以考虑 `any` 逃逸或等 SDK 稳定
- Agent Core 的 Tool Use 处理比较简化（工具结果直接作为 user 消息送回），后续 S002 需要改进为标准的多轮 tool use 循环
