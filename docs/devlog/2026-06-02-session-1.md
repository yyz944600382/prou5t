## 1. 项目定义

用户想开发一个 **回忆 Agent（prou5t）**，核心功能：
- 用户在对话中回忆过去的事 → Agent 提炼为日记 → 持久化存储
- 日记可被检索（关键词 + 语义）
- Agent 拥有跨会话记忆系统

**关键约束（用户纠正）**：只有回忆性内容才提取为日记。讲述的必须是过去的事（跨天以上），当天的事情不记录，哪怕是下午聊上午也不算。prou5t 是回忆捕捉器，不是聊天记录器。

## 2. 技术栈决策

经过讨论确定：
- **语言**：TypeScript + Node.js ≥ 20
- **LLM**：三套适配器（Claude / OpenAI / Ollama），运行时可切换

- **CLI**：@clack/prompts

## 4. 两个重要的概念区分

### 我的记忆 vs Agent 的记忆
- **我的记忆**（Claude Code）：存在 `.claude/memory/`，帮我跨会话恢复开发上下文
- **prou5t 的记忆**：产品功能，存在 `data/` (SQLite)，用户的对话历史压缩
- 两者完全不同，不能混淆

### 记忆 vs 日记
- **日记（Diary）**：目标产物，完整叙述，永久存储
- **记忆（Memory）**：辅助机制，对话压缩，分层衰减
- 日记可以反哺记忆，但存储独立
